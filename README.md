# Campus Rent

An open-source student rental platform built using Flutter and Firebase.

## Problem Statement

Students living away from home often need items temporarily, but purchasing them is expensive and inefficient. Many useful items remain unused in hostels and PGs.

## Solution

Campus Rent enables students to rent items from other students within their local campus/community.

## Features

* User Authentication
* Upload Rental Items
* Browse Listings
* Search & Filters
* User Profiles
* Contact Owner

## Tech Stack

* Flutter
* Firebase Authentication
* Cloud Firestore
* Firebase Storage
